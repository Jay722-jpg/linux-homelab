Linux Homelab Ubuntu Server Deployment
- 
Project Overview
- 
This project documents the deployment and configuration of an Ubuntu Server 24.04 LTS virtual machine using Parallels Desktop.
The objective was to simulate a basic production server environment and practice core Linux system administration tasks including SSH configuration, firewall hardening, and log monitoring.

## Environment 
- Ubuntu Server 24.04 LTS
- Virtualized using Parallels Desktop
- OpenSSH Server
- UFW (Uncomplicated Firewall)

## Tasks Completed
 - Installed Ubuntu Server VM
 - Verified system configuration using hostnamectl
 - Enabled and verified SSH service using systemctl status ssh
 - Configured firewall rules using ufw
 - Monitored SSH authentication logs using journalctl
